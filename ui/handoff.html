Передача программы

К+ на маке

Юридический помощник с доступом к КонсультантПлюс. Слева — что делаете вы, ниже — что делает человек с маком. Установки нет: программа живёт в одной папке и удаляется вместе с ней.

Ваша частьСобрать файл для отправки

Три шага, все на вашем компьютере.

  1. Скачать свежую сборку

    Постоянный адрес, не меняется:

    https://github.com/Ogresssor/k-/releases/latest

    Нужен файл KPlusAgent-portable.tar.gz. Ключа внутри нет — сборка идёт на чужой машине, туда ваш ключ не попадает.

  2. Вложить свой ключ

    В папке проекта:

    python tools/add_env.py путь\к\KPlusAgent-portable.tar.gz

    Получится dist/KPlusAgent-mac.tar.gz — с ключом внутри и с сохранёнными правами на запуск. Просто распаковать и переупаковать вручную нельзя: права потеряются, и приложение не запустится.

  3. Отправить

    Один файл: KPlusAgent-mac.tar.gz, около 59 МБ. Вместе с ним — ссылку на эту страницу.

Внутри файла ваш ключ Gemini

Кто получит архив — получит и ключ. Отправляйте только тому, кому доверяете; при необходимости ключ отзывается в консоли Google.

Часть получателяЗапустить на маке

Две команды один раз, дальше — обычная программа.

  1. Распаковать через Терминал

    Не двойным щелчком по архиву: Finder помечает распакованные файлы карантином, и программа молча не откроется.

    Терминал открывается так: Cmd+Space, набрать «Терминал», Enter. Дальше вставить строку и нажать Enter:

    tar -xzf ~/Downloads/KPlusAgent-mac.tar.gz -C ~/Desktop

    Папка KPlusAgent появится на Рабочем столе.

  2. Снять карантин

    Программа не подписана у Apple, поэтому macOS сначала откажется её открывать. Следующая строка это снимает:

    xattr -dr com.apple.quarantine ~/Desktop/KPlusAgent

    Ответа не будет — так и надо. Терминал больше не понадобится.

  3. Открыть KPlus.app

    Двойной щелчок по приложению в папке. В правом верхнем углу окна должно появиться «готов» и название браузера.

    Дальше можно писать обычными словами: «Напиши претензию в страховую: не выплатили по ОСАГО после ДТП 12.03.2026, отказ от 05.04.2026».

  4. Войти в КонсультантПлюс

    При первом вопросе откроется окно браузера. Логин и пароль вводятся руками — программа их не сохраняет и никуда не передаёт, она лишь запоминает, что вход уже сделан.

    Готовые документы появляются в папке «Документы» рядом с приложением, в двух видах: .docx для Word и .md для быстрого просмотра.

Только одно окно К+

КонсультантПлюс разрешает один сеанс на пользователя и следит, чтобы с разных устройств не работали одновременно. Два браузера на одном компьютере он тоже считает за двух пользователей.

  • Не открывайте К+ в своём обычном браузере, пока работает программа: у неё отдельный профиль, и для К+ это второй вход.
  • Программа всегда работает в одном окне и одной вкладке. Второй запуск честно скажет, что сеанс занят, а не откроет второе окно.
  • Закончили — нажмите «Завершить сеанс К+» в шапке окна. Кнопка видна, пока окно К+ открыто.

Окно К+ намеренно остаётся открытым между вопросами, чтобы не входить заново каждый раз. Но пока оно открыто, сеанс занят.

Что нужно на маке

Любой установленный браузер на движке Chromium: Chrome, Edge, Brave, Vivaldi, Yandex, Arc, Comet. Программа найдёт его сама и ничего скачивать не будет. Если нет ни одного — поставьте Google Chrome обычным способом.

Никакого Python, никакой установки, ничего в «Программы» не копируется. Папку можно перенести куда угодно — программа поедет со всеми данными. Удалить — просто удалить папку.
